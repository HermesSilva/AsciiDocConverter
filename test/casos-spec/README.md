# Casos em que a especificação decide diferente do Asciidoctor 2.0.x

Estes casos **não têm golden**: a regra de fidelidade do projeto (PLANEJAMENTO.md §5.2) manda seguir a
especificação onde ela já decidiu, e o Asciidoctor 2.0.20 (que gera o golden) ainda não a implementa.
Cada arquivo cita a SDR que o justifica. A saída esperada está descrita em docs/fidelidade.md.

Em 2026-10-24 a F3 (`sdr-008-...`) foi revogada: a leitura de itens de lista passou a reproduzir o Asciidoctor
(ver docs/fidelidade.md); o arquivo fica como registro da decisão da especificação.
